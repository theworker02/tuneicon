# tuneicon

Tune encode/decode helpers for icon payloads in pipelines.

**Site:** https://theworker02.github.io/tuneicon/

## Install / run

```bash
git clone https://github.com/theworker02/tuneicon.git
cd tuneicon
node src/cli.js
node --test
```
